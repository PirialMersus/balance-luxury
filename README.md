# Balance — Quiet Luxury Hot Yoga Studio Website

Премиальный цифровой веб-сайт авторской студии горячей йоги **Balance** (Одесса, Украина).

Проект реализован в бескомпромиссной концепции **Quiet Luxury**: благородная молочно-оливковая палитра, аутентичные фотографии пространства, изысканная акцентная антиква Cormorant Garamond в сочетании с функциональным гротеском Manrope, просторные композиции и высокая производительность без избыточного JavaScript.

---

## 1. Концепция и дизайн Quiet Luxury

- **Цветовая палитра природы:**
  - Основной молочный фон: `#F5F1E8`
  - Чистый светлый фон карточек: `#FAF8F2`
  - Песочный оттенок деталей: `#DDD1BE`
  - Приглушённый шалфей: `#9BA18B`
  - Глубокий оливковый: `#424C3B`
  - Тёмно-коричневый графит: `#342C25`
  - Вторичный дымчатый текст: `#777268`
  - Тёплый янтарь горячей йоги: `#C87A54`
- **Типографическая пара:**
  - Заголовки: Cormorant Garamond (сериф с засечками и кириллицей)
  - Интерфейс и основной текст: Manrope (гротеск высокой читаемости)
  - Шрифты бандлятся локально через Fontsource, исключая внешние блокирующие сетевые запросы к Google Fonts и CLS (Cumulative Layout Shift).
- **Композиция:**
  - Чередование полноэкранных фотографий зала и чистых текстовых колонок
  - Отсутствие шаблонных перегруженных карточек с огромными радиусами скругления
  - Поддержка `prefers-reduced-motion`

## 3. Технологический стек

- **Фреймворк:** Astro 5 (Static Site Generation / SSG)
- **Язык:** TypeScript со строгой типизацией (`strict: true`, `strictNullChecks: true`)
- **Стилизация:** CSS с централизованными дизайн-токенами (`src/styles/global.css`)
- **Иконки:** Векторные SVG / Lucide
- **Шрифты:** `@fontsource/cormorant-garamond`, `@fontsource/manrope`
- **SEO & Structured Data:**
  - Семантическая разметка HTML5
  - Метатеги Open Graph, Twitter Card, canonical link
  - Микроразметка Schema.org (`HealthAndBeautyBusiness`, `Article`)
  - Автогенерация карты сайта `sitemap-index.xml` и файла `robots.txt`
  - Атрибуты `fetchpriority="high"` и `loading="eager"` для LCP-изображений первого экрана

## 5. Быстрый запуск и разработка

### Установка зависимостей:
\`\`\`bash
npm install
\`\`\`

### Запуск локального dev-сервера:
\`\`\`bash
npm run dev
\`\`\`
Сайт доступен по адресу `http://localhost:4321`.

### Проверка типов TypeScript и целостности Astro:
\`\`\`bash
npm run check
\`\`\`

### Сборка production-версии:
\`\`\`bash
npm run build
\`\`\`

### Локальный просмотр production-сборки:
\`\`\`bash
npm run preview
\`\`\`
